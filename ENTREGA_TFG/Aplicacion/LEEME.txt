PlotSkip / Plotea

Estructura de entrega

- Documentacion
- Presentacion
- Aplicacion
  - Back
  - Front
  - BBDD
  - APK

1. Documentacion

En esta entrega final, la memoria debe ir en PDF. Mientras tanto, este paquete contiene el documento fuente `TFG_Plotea_final.docx` para que puedas convertirlo a PDF sin rehacer nada.

2. Presentacion

El archivo de defensa es `plotea-presentacion-tfg.pptx`. No se debe modificar tras la entrega porque es el que se usara en la defensa.

3. Aplicacion

3.1. Back

Ruta: `Aplicacion\Back`

Pasos recomendados para levantar el backend en local:

```powershell
cd Aplicacion\Back
py -3.12 -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

Crear `Aplicacion\Back\.env` con, al menos:

```env
DATABASE_URL=postgresql+asyncpg://usuario:password@host:5432/plotskip?sslmode=require
SECRET_KEY=una-clave-larga-y-segura
TMDB_API_KEY=tu-clave-tmdb
RESEND_API_KEY=tu-clave-resend
RESEND_FROM_EMAIL=onboarding@resend.dev
PASSWORD_RESET_BASE_URL=
PASSWORD_RESET_APP_URL=plotskip://reset-password
UPLOADS_DIR=
```

Migraciones y arranque:

```powershell
alembic upgrade head
uvicorn app.main:app --reload
```

3.2. Front

Ruta: `Aplicacion\Front`

Instalacion y arranque:

```powershell
cd Aplicacion\Front
npm ci
```

Crear `Aplicacion\Front\.env.local` con:

```env
EXPO_PUBLIC_BACKEND_URL=http://localhost:8000
```

Si trabajas contra el backend desplegado, usa:

```env
EXPO_PUBLIC_BACKEND_URL=https://plotea-production.up.railway.app
```

Arranque:

```powershell
npm run start
```

3.3. BBDD

Ruta: `Aplicacion\BBDD\script_bbdd.sql`

Ese archivo recoge el esquema SQL actual del proyecto para PostgreSQL. Si prefieres el flujo oficial del backend, las migraciones equivalentes estan en `Aplicacion\Back\alembic\versions`.

4. Credenciales y configuracion

- No hay cuentas precargadas en la aplicacion final.
- Para probar el sistema en local, crea un usuario nuevo desde la pantalla de registro.
- Las credenciales tecnicas principales son las variables de entorno del backend y `EXPO_PUBLIC_BACKEND_URL` en el front.
- En despliegue real, el backend actualmente responde en `https://plotea-production.up.railway.app`.

5. APK

- La carpeta `Aplicacion\APK` queda reservada para la APK o el `.exe` final.
- Cuando la tengas, coloquela ahi antes de comprimir el ZIP final.
